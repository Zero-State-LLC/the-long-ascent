# THE LONG ASCENT — Visual Asset Map

## Rendering contract

| Token | Specification |
|---|---|
| Visual principle | Keep the figure graphically simple across all eras; vocabulary, props, palette, and substrate evolve, not drawing complexity. The on-screen figure is the current lineage carrier. |
| Coordinate space | Canvas normalized to 100×100; origin top-left. Figure baseline y=88, head radius 5, torso from (50,43) to (50,67); shoulder (50,48), hip (50,66), default limbs use jointed line segments. Scale uniformly to fit. |
| Stroke | Figure and prop outlines round-cap/round-join; default width 2.2 units, head outline 2.0. Tiny-screen minimum 1.5 CSS px. Avoid facial detail except optional two eye dots in close-up. |
| Pose notation | Points are normalized (x,y); pose table gives variable joints/prop anchors; unlisted joints use the coordinate-space defaults. Prop anchors attach to hands unless specified. Mirror left/right poses where appropriate. |
| Color notation | Hex colors are opaque sRGB; `--ink` is the primary figure stroke and `--accent` the highlighted prop/interaction color. Use patterns, labels, and luminance differences as well as color for state distinction. |
| Motion | Idle: subtle ±1-unit breathing over 3.2s; transition: cross-fade palette and interpolate pose over 700ms; no rapid flashing. Respect reduced-motion by freezing idle and replacing transitions with 150ms fades. |

## 3. UI element inventory

| Element | Variants / contents | Visual behavior and tokens |
|---|---|---|
| Resource bar | Six persistent pools: Sustenance (era-keyed label), Knowledge, Population/Instances, Infrastructure, Legitimacy, Entropy; current value, rate, cap/overflow where relevant. | DOM shell; compact horizontal rows on wide screens, stacked/collapsible on narrow screens; icon plus text label and numeric value; entropy uses warning hue and pattern, not hue alone. |
| Era header | Era number/name, signature resource, current carrier/copy count, era progress. | Era palette accent; clear title hierarchy; progress indicator shaped as a continuous ascent line. |
| Era progress | Fill bar, threshold, optional milestone ticks. | 0–100%; animate only on material change; reduced-motion updates immediately; accessible text equivalent. |
| Allocation controls | Resource allocation +/- buttons or stepper; current allocation and effect preview. | Large tap targets; disabled state is visibly distinct and semantically disabled; never use color as only state cue. |
| Primary action button | Advance/trigger, recruit, research, trade, or era-specific action. | Solid `--accent` fill, high-contrast label, pressed/hover/focus states; one dominant action per panel. |
| Choice cards | 2–4 branching options with short title, consequence hints, confirm action. | Distinct card hit areas; selected outline + check icon; consequence text must remain readable; no irreversible action conveyed by color alone. |
| Event modal/card | Event title, body, procedural pose/prop slot, choices. | Scrim plus centered panel; on small screens use near-full-height sheet; keyboard focus contained and returned on close. |
| Chronicle panel | Ordered choice log, era stamps, filter/search, linked flags referenced by later events. | Scrollable timeline; era color marker plus textual era; entries distinguish decision/outcome. |
| Lineage panel | Carrier, heir/die state, fork copies, merge action, divergence/opinion status. | Small node graph; solid line for merged lineage, dashed for fork; support text labels and copy count. |
| Entropy/pollution indicator | Persistent risk meter, trend, source tooltip. | Patterned fill and warning glyph; retain visibility across eras; avoid pulsing/flashing. |
| Resource icons | Food/grain/coin/faith/books/coal/oil/fissile/compute/attention/selfhood; knowledge, population/instances, infrastructure, legitimacy, entropy. | Inline vector/canvas primitives, 16/20/24px sizes; monochrome silhouettes with era accent; always pair with accessible text label. |
| General icon set | Fire, tool, land, trade, law, legion, monastery, book, press, gear, factory, smoke, oil drop, bomb/clock, chip, agent, phone/attention, upload, fork, merge, star system, settings, help, pause, close, back, save/export/import. | 24-unit viewbox; 2-unit rounded stroke; 1–2 colors; consistent silhouette; icons are procedural/vector primitives, no raster dependencies. |
| Navigation | Era overview, Chronicle, lineage, settings/help, save management. | Tab/navigation rail on wide layout; labeled bottom navigation or menu on narrow layout; active marker includes shape and text. |
| Settings panel | Sound, text size, reduced motion, contrast, save export/import, reset confirmation. | DOM-native controls; explicit confirmation for destructive reset; import/export operates offline. |
| Tooltip/help | Resource definitions, rates, mechanic hints, glossary. | Trigger on hover/focus/tap; short, dismissible, never sole source of critical instructions. |
| Toast/status | Autosave, event outcome, import/export result, offline status. | Non-blocking, text + status icon; announce through an accessible live region; timeout adjustable or manually dismissible. |
| Empty/loading/error states | First launch, no Chronicle entries, save parse error, unsupported storage. | Match current era tokens; plain-language recovery action; never imply cloud sync. |
| Focus and disabled states | Keyboard focus ring, pressed, hover, selected, disabled. | Focus ring ≥2px with offset; preserve contrast; disabled controls retain readable labels and explain unavailable reason where useful. |
